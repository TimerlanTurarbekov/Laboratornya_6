# Анализ общественного мнения о бренде Apple на основе текстовых данных из социальных сетей

## Описание работы
Данный проект посвящен анализу общественного мнения о бренде Apple с использованием методов обработки естественного языка (NLP). Для исследования применяются текстовые данные из социальных сетей (Twitter), содержащие реальные пользовательские высказывания о компании и ее продуктах. В работе проводится предобработка данных, обучение нескольких моделей анализа тональности, их сравнение и визуализация результатов.

## Цель работы
Изучить методы анализа текстовых данных и на практике применить инструменты NLP для выявления настроений пользователей, сравнения эффективности различных моделей и построения визуальной аналитики.

## Используемые данные
В качестве источника данных использован открытый набор:
Apple Tweets Sentiment Dataset (Kaggle)

Датасет содержит тексты твитов с разными типами настроения: негативное, нейтральное и позитивное отношение к бренду Apple.

## Этапы работы
1. Сбор данных  
Данные загружены из открытого корпуса Kaggle с использованием библиотеки kagglehub.

2. Предобработка текста  
Выполнены основные операции NLP-подготовки:
- приведение текста к нижнему регистру  
- удаление ссылок  
- удаление упоминаний пользователей (@)  
- удаление хештегов (#)  
- удаление спецсимволов  
- очистка пробелов  

3. Обучение моделей  
Реализовано обучение двух моделей анализа тональности:
- TF-IDF + Naive Bayes  
- TF-IDF + Logistic Regression  

4. Оценка качества  
Проведено сравнение моделей по метрикам:
- Accuracy  
- F1-macro  

Также выполнен анализ ошибок классификации на примерах неверных предсказаний.

5. Визуализация результатов  
Построены:
- распределение настроений пользователей  
- интерактивные графики (Plotly)  
- облако слов для позитивных и негативных сообщений  

## Результаты
В ходе эксперимента показано, что логистическая регрессия демонстрирует более высокую точность по сравнению с Naive Bayes. Анализ ошибок показал, что модели чаще испытывают сложности при обработке неоднозначных, длинных и саркастических сообщений. В целом проект подтверждает, что методы NLP позволяют эффективно исследовать общественное мнение и выявлять отношение аудитории к бренду Apple.

## Вывод
Выполнен полный цикл анализа текстовых данных: от получения и предобработки текстов до обучения моделей, оценки результатов и визуализации. Работа демонстрирует практическое применение методов NLP для анализа общественных мнений и исследования настроений пользователей в социальных сетях.
